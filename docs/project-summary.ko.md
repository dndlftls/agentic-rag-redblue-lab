# 에이전트 RAG 오염 공격 방어 연구 — 프로젝트 보고

| 추진배경 | |
| --- | --- |

◦ **RAG는 검색된 문서를 근거로 답하므로, 코퍼스가 오염되면 모델이 정상이어도 오답을 사실로 진술함**

  - 본 랩 구현 PoisonedRAG(USENIX Security 2025)는 검색 조건과 오답 유도를 한 문서에
    결합(`P = Q ‖ I`)하고, 실제 모델로 성공을 검증한 문서만 주입하는 강한 공격임
  - 무방어 실측 결과 **ASR 0.75 · 정답률 0.00**이며, 오염문이 top-5를 8/8 시나리오에서
    완전 점유하여 정답 문서가 한 건도 검색되지 않았음

◦ **다중 에이전트·장기 메모리 구조로 인해 단순 LLM 보안이 아닌 에이전트 보안 관점이 필요함**

  - 검색 에이전트 3종을 호출하는 구조로 한 경로의 오염이 전체 답변을 좌우하며,
    오염 상태에서 생성된 답변이 메모리에 저장되면 이후 세션에서 재인용될 수 있음

◦ **방어 논문은 다수 존재하나 본 환경(밀집 검색기·LLM 생성 오염문)에서 검증된 바 없어, 과제를 "직접 구현 후 실측"으로 설정하였음**

◦ **에이전트 장기 메모리 및 오염 전파 차단** *(upstream 병합, PR #8)*

  - 세션별 대화 메모리에 **신뢰 전파**를 적용 — 근거 문서가 전부 신뢰 문서일 때만 해당
    turn을 신뢰 상태로 저장하여, 오염이 메모리를 타고 다음 세션으로 번지는 경로를 차단함

◦ **검색 단계 방어 3종 구현·실측** *(RAGPart 병합, PR #7)*

  - RAGPart·RAGMask(arXiv:2512.24268)는 **무효**로 확인(RAGMask는 ASR 0.88로 역효과).
    두 기법 모두 문서를 개별적으로 질의와만 비교하는데, 오염문(0.75)과 정답 문단
    (0.74~0.84)의 유사도 구간이 겹쳐 원리적으로 구별 불가함
  - 대안으로 **중복성 필터**를 자체 구현함. 공격이 질의당 다수 오염문을 주입하고 전부
    같은 오답을 주장하는 점에 착안하여, 서로 지나치게 유사한 후보군을 제거함.
    임계값 0.90은 관측값(정상 최대 0.8705 ↔ 오염 최소 0.9382) 사이에서 결정하였음

◦ **생성 단계 방어 3종 구현·실측**

  - RobustRAG 논문 원안(SaTML 2026, 문서별 격리 답변 후 키워드 집계)은 단독으로
    ASR 0.75 → 0.50 달성
  - **절제 실험으로 이득의 출처를 규명함** — 자체 변형(충돌 탐지)이 좋은 수치를 보였으나,
    격리만 적용 시 0.75 / 충돌 규칙 추가 시 0.62로 측정되어 **이득은 전적으로 논문의
    격리에서 발생**하고 자체 변형은 성능을 저하시킴을 확인, 관련 주장을 철회하였음

◦ **방어 on/off 토글 및 재현 가능한 측정 체계 구축** — 요청 단위·배포 기본값·마스터
  스위치 3단계, 측정 스크립트 2종(공격 하 비교 / 무공격 오탐 비용)

**※ 핵심 실측** (오염문 5개 · 8시나리오 · top-5 · `nomic-embed-text` · qwen3:8b)

    17/20 → 17/20, 1/20 질의에서만 발동 → **상시 적용 가능 수준**

◦ **방어 도입 시 근거에 기반한 선택이 가능해짐** — 본 환경 기준 효과·비용·오탐률 실측치
  확보. 권장 구성은 **중복성 필터(검색) + isolation(생성)**이며, 임계값이 측정에서
  유도되므로 검색기·코퍼스 변경 시에도 동일 절차로 재산출 가능함

◦ **부정 결과 4건 확보로 후속 연구의 탐색 범위가 축소됨** — 특히 "문서를 개별적으로
  질의와만 비교하는 계열은 본 공격에 원리적으로 취약함"은 개별 기법이 아닌 **해당 계열
  전체의 사전 배제 근거**로 활용 가능함

◦ **방어 사각지대가 특정되어 차기 과제가 명확해짐** — 오염문 1개 구간은 군집이 형성되지
  않아 원리적으로 대응 불가(파라미터 조정으로 해결 불가)하며, 해당 구간 공격 성공률이
  60~70%로 낮지 않음. 이에 **단일 오염문 대응** 및 **에이전트 실행 격리**(IsolateGPT,
  NDSS 2025)를 차기 과제로 도출하였음

◦ **측정 방법론이 재사용 가능한 자산으로 확보됨** — 신규 방어 추가 시 동일 조건 비교가
  즉시 가능하며, 측정 함정(임베딩 백엔드 미지정 시 테스트용 값이 사용되어 결과가
  무의미해지는 문제, 실제 1세트 폐기)을 로그·가드로 차단함
